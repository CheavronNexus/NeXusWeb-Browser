# Security Policy for NeXusWeb

**Chevron Nexus Software** takes security and privacy very seriously. We appreciate your efforts to responsibly disclose any security vulnerabilities.

---

## 🔒 Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 6.5.x   | :white_check_mark: |
| < 6.5   | :x:                |

---

## 🛡️ Reporting a Vulnerability

If you discover a security vulnerability in NeXusWeb:

1. **Do not disclose it publicly** until it has been reviewed and addressed.
2. Email your report directly to **security@chevronnexus.com** or open a confidential security advisory on GitHub.
3. Include:
   - Type of issue (e.g., sandbox escape, WebRTC IP leak, privilege escalation, XSS).
   - Step-by-step instructions to reproduce the issue.
   - Proof-of-concept code or demonstration.
   - Affected platform and NeXusWeb version.

We will acknowledge receipt within 48 hours and work with you on a patch and disclosure schedule.
